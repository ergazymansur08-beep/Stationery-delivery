How to Run Locally
1)Clone the repo: https://github.com/ergazymansur08-beep/Stationery-delivery
2)Go to backend folder, install dependencies: pip install -r requirements.txt
3)Run FastAPI server: uvicorn main:app --reload
4)Open frontend/index.html in your browser.
